# AI 智能体安全调研报告

![AI 智能体安全调研报告封面](public/report-cover.png)

《AI 智能体安全调研报告》围绕 AI 智能体从技术研发到产业部署过程中面临的新型安全问题展开系统调研，重点分析智能体在自主规划、长期记忆、工具调用、多智能体协同和真实环境交互中的风险机理、防护能力与攻防演化趋势。

报告由中国科学院计算机网络信息中心网络空间安全技术与应用发展部编制。本项目将报告正文、图表和参考文献转化为交互式网页，便于研究人员、产业从业者和安全管理人员按专题浏览、检索与比较。

> 当前收录版本：2026 版（终稿），发布于 2026 年 7 月 31 日。报告共 171 页，包含 48 张表、22 幅图和 1143 条参考文献。

## 调研背景

AI 智能体正从基于大模型的对话工具演进为能够持续感知环境、保存状态、拆解任务、调用外部工具并自主执行操作的复杂系统。能力边界的扩张使其安全问题不再局限于模型输出内容，而是进一步延伸至身份权限、记忆数据、工具供应链、运行环境、软硬件基础设施和组织治理等层面。

与传统大模型相比，智能体风险具有以下特点：

- **攻击面系统化**：风险贯穿模型、记忆、插件、协议、API、操作系统、云资源和物理设备。
- **攻击链条化**：单点提示注入可能沿规划、工具调用和多智能体协作链路持续传播。
- **行为动态化**：长期任务和多轮交互会引入目标漂移、状态污染和权限累积问题。
- **后果现实化**：智能体能够直接读写文件、操作业务系统、访问数据并执行高危动作。
- **治理复杂化**：模型提供方、平台、工具开发者、部署组织与终端用户之间的责任边界尚不清晰。

## 调研框架

报告以“全生命周期阶段 × 核心能力模块”为主要分析框架。

### 七个生命周期阶段

1. **需求规划**：研究安全目标、能力边界、合规约束和风险建模是否被前置纳入需求。
2. **架构设计**：分析模型、记忆、工具、身份和治理组件之间的信任边界与隔离机制。
3. **编码开发**：关注智能体框架、插件依赖、代码生成、密钥使用和供应链引入的风险。
4. **安全测试**：评估静态基准、动态红队、长时序任务和跨模块攻击测试的覆盖能力。
5. **部署交付**：研究模型制品、运行配置、容器环境、权限基线与交付证据链的可靠性。
6. **运行维护**：分析实时监控、异常阻断、审计溯源、权限回收和持续更新能力。
7. **退役下线**：关注记忆、凭证、日志、模型副本和业务数据的完整清理与责任闭环。

### 六类核心能力

| 能力模块 | 主要安全议题 |
| --- | --- |
| 感知 | 恶意输入、间接提示注入、多模态载荷和环境信息污染 |
| 记忆 | 长期记忆投毒、敏感信息残留、跨用户串扰和检索越权 |
| 决策 | 目标漂移、策略操纵、错误规划和安全约束衰减 |
| 行动 | 工具滥用、越权调用、代码执行、文件与业务系统破坏 |
| 交互 | 身份冒用、多智能体信任传递、通信劫持和隐私泄露 |
| 治理 | 责任划分、策略管理、合规审计、事件追踪和风险量化 |

## 主要调研内容

### 1. 全球研究与产业格局

报告梳理北美、欧洲和中国在 AI 智能体安全领域的高校团队、科研机构、企业实验室与产学合作情况，比较不同区域在基础模型安全、智能体评测、运行时治理、隐私计算、可信硬件和行业落地方面的技术路线。

调研特别关注开源基础模型与智能体安全底座、云端企业级智能体、自动化红队评测、MCP 工具协议、中文安全评测体系，以及国产软硬件生态中的安全适配问题。

### 2. 产品、平台与工程防护

报告对全球主流 AI 智能体产品及安全能力进行整理，分析模型护栏、智能体网关、身份权限、人在回路审批、运行时追踪、内容安全、沙箱隔离、插件审核和资产管理等工程方案。

相关比较覆盖北美、欧洲与中国的模型厂商、云服务商和专业安全企业，并讨论不同产品在开放生态、企业治理、私有化部署、行业合规和国产化适配方面的优势与局限。

### 3. 安全事件、漏洞与攻击工具

报告汇总智能体相关安全事件、典型漏洞和自动化攻击工具，涵盖提示注入、记忆投毒、工具劫持、远程代码执行、沙箱逃逸、供应链污染、权限提升、数据泄露与多智能体级联风险。

这些案例表明，智能体安全事件往往不是单一模型缺陷造成的，而是由不可信输入、过度授权、工具链漏洞、运行环境缺陷和审计能力不足共同形成的系统性风险。

### 4. 硬件与基础设施安全

随着智能体进入云平台、浏览器、终端、机器人和工业设备，安全边界进一步下沉至 GPU、NPU、CPU、可信执行环境、固件、驱动和边缘设备。

报告调研了侧信道攻击、机密计算、可信启动、硬件信任根、芯片供应链、国产算力适配和私有化部署等方向，并比较不同地区在高性能计算、工业控制与自主可控方面的安全需求。

### 5. 政策法规与安全治理

报告整理全球主要国家和地区的 AI 安全政策、行业规范与出口管制措施，关注智能体自主行为带来的数据保护、透明度、人类监督、事件报告、责任追踪和高风险应用治理问题。

调研显示，现有制度多由通用人工智能、网络安全、数据保护和产品责任规则延伸而来，面向智能体跨系统行动、多主体协作和动态权限管理的专门治理框架仍处于形成阶段。

### 6. 防护体系与发展趋势

报告从需求、架构、研发、测试、部署、运行和退役各阶段归纳现有安全方案，并分析其适用范围与能力边界。现有防护正在从单点内容过滤向身份、权限、工具、记忆、运行时和供应链的全链路治理演进，但跨模块联动、长时序风险识别和动态自适应防护仍是突出短板。

未来研究需要进一步推进：

- 面向智能体的统一威胁模型和全生命周期安全参考架构
- 长期记忆、动态规划与多智能体协同过程的可验证安全
- 工具调用协议、插件市场和智能体供应链的标准化治理
- 基于最小权限、动态授权和可回滚执行的行动安全机制
- 覆盖真实业务链路的持续红队测试与量化评测体系
- 模型、软件、云平台与可信硬件协同的纵深防御体系
- 可审计、可追责且适配不同地区监管要求的治理机制
