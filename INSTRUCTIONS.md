# Local Development Instructions

## 1. Clone Project

Download the project source code from GitHub.

## 2. Check Environment Version

Check Node.js version

```bash
node -v
```

Expected: `v22.22.2`

Check npm version

```bash
npm -v
```

Expected: `10.9.7`

## 3. Enter Project Directory

```bash
cd SecurityReport
```

## 4. Install Dependencies

```bash
npm install
```

## 5. Start Dev Server

```bash
npm run dev
```

## 6. Access Local Page

Open in browser:

```Plain Text
http://localhost:5173/
```

## 7. Modify Code \& Verify Effect

Modify the TSC \(TypeScript\) code, then check the real\-time updated effect on the website page.
